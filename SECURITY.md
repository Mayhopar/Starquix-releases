# Security policy

## Supported versions

Only the [latest release](https://github.com/Mayhopar/Starquix-releases/releases/latest) receives fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through [Security → Report a vulnerability](https://github.com/Mayhopar/Starquix-releases/security/advisories/new).

Include what you found, the steps to reproduce it, and your Starquix and macOS versions.
